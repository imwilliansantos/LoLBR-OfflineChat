# LoLBR-OfflineChat

A C# project focused on offline chat functionality for LoLBR.

## 📌 About

LoLBR-OfflineChat is a desktop application developed in C# with Windows Forms. The project explores offline chat functionality related to LoLBR.

## 🛠️ Technologies

- C#
- .NET
- Windows Forms
- Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Windows
- .NET SDK compatible with the project

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/imwilliansantos/LoLBR-OfflineChat.git
   ```

2. Navigate to the project directory:

   ```bash
   cd LoLBR-OfflineChat
   ```

3. Run the application:

   ```bash
   dotnet run
   ```
